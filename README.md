# Projeto_ONG
Projeto de experiência prática em HTML5 para uma ONG fictícia.

## Estrutura do projeto

O projeto está organizado em arquivos HTML, CSS, JavaScript e imagens, separados por pastas para facilitar a manutenção e a organização do código.

## Versionamento

O projeto utiliza Git para controle de versões e GitHub para hospedagem do repositório. O desenvolvimento segue uma organização baseada em branches, com `main`, `develop` e branches específicas para novas funcionalidades.

## Acessibilidade

O projeto possui melhorias de acessibilidade no menu de navegação, incluindo o uso de botão, atributos ARIA e controle da abertura e fechamento do menu por JavaScript.
